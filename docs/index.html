📖 如何获取 Google 账号 Cookie？

由于 Google 激活链接必须在登录状态下才能识别套餐详情与活性状态，因此需要提供您的 Google Cookie：

步骤一：打开 Chrome 浏览器
在 Chrome 中登录您的任一 Google 账号并打开 https://one.google.com
步骤二：按 F12 打开开发者工具
点击顶部 「网络 (Network)」 选项卡，刷新页面，点击左侧列表中第一个 one.google.com 或 app?awwd=... 请求。
步骤三：复制 Cookie 标头
在右侧 「标头 (Headers)」 -> 「请求标头 (Request Headers)」 中找到 Cookie: ...，鼠标右键点击并复制该值。
步骤四：粘贴并保存
回到本工具，点击右上角 「配置」，粘贴到 Cookie 文本框中，点击保存即可！
